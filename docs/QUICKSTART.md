# Discord A0 quick start

1. Install https://github.com/3clyp50/discord-a0 with Agent Zero's Plugin Installer.
2. Create a Discord bot, enable Message Content Intent and invite it to your server.
3. In **Discord A0 > Config**, add its token, access rules and optional instructions.
4. Save, then start it with the play icon on its row.
5. Mention the bot or reply to it in Discord.
6. For full agent tools, approve the recorded user/channel under **Agent access**.

Use a separate token for each additional bot. Disable any older Discord integration
before moving the same token here. Existing settings and approvals are not imported.

See [Setup](SETUP.md) and [Chat Bridge Guide](CHAT_BRIDGE.md) for permissions,
file attachments, slash commands and on-demand skills.

# Discord A0 1.2.0

Standalone repository: https://github.com/3clyp50/discord-a0

Maintained by 3clyp50. Derived from spinnakergit's Discord integration; the
original Git history and MIT license are retained.

## Changes

- Multiple bots with per-bot instructions, model presets and agent profiles.
- Mention/reply chat routing, scoped WebUI approvals and persistent grants.
- Two baseline tools, with optional research and administration skills.
- File attachments, final-delivery receipts and duplicate-message protection.
- Agent Zero configuration components and white-on-blurple thumbnail.
- Independent `discord_a0` plugin identity, settings routes and skill names.

## Installation

Use Agent Zero's Plugin Installer with the repository URL above. Plugin Index
availability depends on review of the separate submission to agent0ai/a0-plugins.

Disable the older Discord plugin before enabling this version. Settings, access
approvals and chat mappings are not migrated automatically. See README.md.

Historical security reports describe earlier versions, not an audit of this release.
